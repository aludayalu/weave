How the pipeline runs

Importing collects commits, pull requests and messages into a single timeline. Then run the pipeline, which cleans that into silver, asks a model where each task window began and ended, validates every window against the records it claims, and slices the result into a training dataset. It is scored against a deterministic baseline, and the baseline wins ties.

A run takes a few minutes. You can close this page.
