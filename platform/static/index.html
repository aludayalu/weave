The pipeline

Three steps, no magic

A model proposes where each task started and ended. Static code checks every proposal against the source before a single byte reaches your dataset.

1

Connect

A public GitHub repo, or upload a Discord export. weave reads commits, pull requests and messages, and links them into a single timeline.

2

Detect

A model proposes task windows. Each one is validated against the records it claims to cover, and scored against a deterministic baseline. If the model does not beat the baseline, the baseline wins.

3

Serve

You get an OpenAI compatible endpoint. Point an existing client at it, mint a key, and keep working. Every call is metered and logged.
