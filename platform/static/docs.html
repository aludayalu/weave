API

Reference

weave speaks the OpenAI chat completions shape, so an existing client only needs its base URL and key changed.

Authentication

Send your key as a bearer token. Keys are created in the dashboard under API keys and shown once. 

Authorization: Bearer wk-...

Chat completions

POST /v1/chat/completions
curl https://your-app.databricksapps.com/v1/chat/completions \
  -H "Authorization: Bearer $WEAVE_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "weave",
    "messages": [{"role": "user", "content": "how do we cut a release?"}]
  }'
model
Optional. Defaults to weave.
messages
Required. Standard OpenAI message array.
max_tokens, temperature
Accepted, for client compatibility.
stream
Accepted but not yet implemented. Set false.

Models

GET /v1/models
Lists the model versions your account has produced.

Errors

401
Missing or unknown API key.
400
The request was malformed, usually an empty messages.
502
Generation failed. The reason is in the response body.
Python example. 
from openai import OpenAI

client = OpenAI(
    base_url="https://your-app.databricksapps.com/v1",
    api_key="wk-...",
)
reply = client.chat.completions.create(
    model="weave",
    messages=[{"role": "user", "content": "how do we cut a release?"}],
)
print(reply.choices[0].message.content)
